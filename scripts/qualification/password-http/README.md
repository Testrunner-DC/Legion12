# 真实认证HTTP的有界容量资格

这是QA工具，不是另一个认证实现或发布入口。编译时只引用明确指定的已验服务器DLL，运行时以SHA绑定并加载同一服务器原件；没有服务器项目引用或源码副本。`L12PasswordCredential.Create`和原平台事务仅用于在新建私有库中准备合成600k记录，正常写入成本不变。

`drive.py`用独立进程发真实HTTP请求，避免客户端与服务器共享线程池。每个成本窗口为：1次预热、4次串行成功登录、1/2/4/8并发登录且每组附带10次已认证读取、6次错误密码及6次限流边界请求。每窗口32次登录请求和44次读取；另对每次成功返回的token实际调用me核对本人身份，最多20次，单列且不并入登录耗时。成功、401、429和503分别保留原始数值样本，不把拒绝计成成功吞吐。串行仅4个样本，最近秩P95就是最大值，不是长期尾延迟保证。

每个并发登录槽使用不同的合成账号（共8个，另有1个读取账号），避免同一账号的既有4会话保留上限使刚返回的旧token被后续登录正常淘汰。保留原会话规则，不为资格工具修改产品上限；10次外围读取是并行读取请求，不冒10名独立用户或完整30＋10。

## 固定安全边界

- 父进程创建全新环境白名单；服务器构造前拒绝任何继承的管理员密码、共享图库或ASP.NET/Kestrel配置。合成管理员密码只在隔离进程中随机生成。
- 只允许127.0.0.1动态端口、父TEMP下新建空`l12-auth-http-*`目录、无链接祖先及独立cwd；不读取既有账号库、运行配置或真实口令。
- 准备握手中的合成口令／token只通过私有管道保留在内存；证据仅状态码、具名错误类别、Retry-After、字节、耗时与清退布尔值。不打印异常正文或响应内容。
- 私有HTTP客户端明确禁用代理及自动跳转；正确口令拒绝401／429、错误口令拒绝200、200必须绑定合成身份并验证token，非认证繁忙503也不混入保护成功。
- 先停止发送并收齐请求，再核凭据未改、撤销全部合成会话、停止服务。子进程退出且成功后只删除这一个已验证无链接的合成树；失败树私有保留。
- 每窗口客户端35秒／服务器等候40秒，外层进程仍须硬截止；目标主机以nice19运行。`--live-guard`只读固定两服health和PID，身份／维护改变或3秒health失败立即停止。
- 不部署、不重启既有服务、不启600k写入或迁移，不声称公网TLS／反代耗时、新30＋10、600k注册或渐进升级已经通过。

## 运行

先使用权威`L12GeneratedStorage.ps1`验证D盘证据／缓存／短TEMP并初始化依赖。编译必须给`-p:L12ServerAssemblyRoot=<已验服务器程序目录>`，输出复用小型`g4-password-probe`热根。先运行`test-l12-password-http-probe.py`的环境／参数／非空目录反例，再由`drive.py`以显式绝对dotnet、probe、server-root、server-sha256和temp-base运行。不要从生产shell直接裸跑probe；`drive.py`才负责创建白名单环境和私有cwd。

完成本机边界及真实HTTP正控后，目标主机只上传小工具的dll／deps／runtimeconfig和驱动，不上传数据库、私钥或配置；在一次有界临时目录内读取当前已验发布的程序，现场核对原件SHA与两服身份。原始完整数值与现场收据绑定，不用本机速度代表服务器容量。

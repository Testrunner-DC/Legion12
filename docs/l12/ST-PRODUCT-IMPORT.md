## 卡效写入边界

第一批只接管低歧义、可复用的结构化能力，共13项，覆盖抽牌、追加士气、获得符文、试炼推进、冲锋和当回合进攻权限等。数据库 `ABILITY` 分段进入后台原子清单，但只有标记为已验证并存在运行时程序的能力才视为实装。

远程能力的权威判断是结构化后存在：

> 进攻距离+1，远程进攻无损。

因此弓手和术师都可能是远程，其他职介若具有相同能力也同样按远程处理；反过来不能仅凭“弓手”或“术师”名称推断。由效果明确“视为【弓手】”的派生职介则取得弓手公共能力。

后续批次依次处理：

1. 带公开或隐藏目标的能力；
2. 费用、替代、追加支付与复合效果；
3. 主宰、天灾、阵营机制及特殊区域；
4. 全卡逐能力审计与发布级回归。

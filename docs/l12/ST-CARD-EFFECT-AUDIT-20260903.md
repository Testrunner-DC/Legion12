# ST 卡效全量审计（2026-09-03）

## 审计结论

- ST01–ST06 共 76 张卡，其中 69 张有效果文本、7 张无效果卡。
- 69 张效果卡共拆出 121 个由数据库人工维护的 `ABILITY` 边界。
- 69 张效果卡均能在运行时证据目录中找到入口；没有仅导入文本、完全没有运行入口的 ST 效果卡。
- 41 张效果卡已进入细粒度原子程序；其余 28 张仍通过共享结构化规则或复合程序运行。后者“可执行”不等于“已经逐能力细原子化”，后续迁移不能混为同一个指标。
- ST 专项测试由原有 49 项增至 51 项；新增两项全目录结构守卫，固定 76 张卡、7 张无效果卡、121 个能力边界和共享规则入口。

- 资源清单已缓存时同步取得真实卡图；未完成解析时显示稳定暗色外壳，不预先显示占位图。

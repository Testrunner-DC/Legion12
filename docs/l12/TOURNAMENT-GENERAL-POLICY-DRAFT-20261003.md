# 十二军团赛事通则（审阅草案）

日期：2026-10-03。状态：待确认，未发布。

以下为完整规程建议稿，不是已生效规则。`*`表示仍需确认的数值、方式或权限；发布前必须填齐。全文确认后才可作为赛事规则使用。与线上已实现功能的差异见文末，不能用本草案宣称管理功能已完成。

## 一、赛事公告与规则

1. 主办方在报名开始前公布赛制、参赛资格、人数上限、报名与签到时间、预计赛程、奖项、裁判名单和本赛事规程。
2. 比赛采用已公布的规则、卡牌勘误和禁限卡。赛事固定规则版本；进行中不追溯更换规则，紧急安全或严重公平问题由主裁判作公开说明并决定中止、延期或取消。
3. 赛制为`*`，每场采用`*`局制；胜/平/负积分分别为`*`/`*`/`*`，轮空积分为`*`。同分排序依次为`*`。晋级人数为`*`。
4. 公告中的时间均明确时区，时长统一以分钟表示。报名截止、签到结束和开赛时间分别为`*`、`*`、`*`。
5. 同一玩家不得使用多个账号重复参赛，不得代打、串通或利用工作人员权限获得不正当优势。

## 二、报名、签到与牌库

1. 报名不要求提交牌库；赛前签到时选择牌库，合法性校验通过后锁定本次参赛构筑。锁定失败不视为签到完成。
2. 签到后不得私自修改比赛构筑。是否允许备选区及换牌、换牌范围、提交方式与时限为`*`，没有明确许可不得自行换牌。
3. 截止时未完成签到的处理为`*`。候补递补按`*`顺序进行，截止时间为`*`；不得在未公告规则的情况下临时替换已确定的参赛者。
4. 牌库锁定与历史来源版本用于核验，不向其他参赛者暴露未公开构筑。是否公开完整牌表、公开时间与范围为`*`。

## 三、入场、迟到与缺席

1. 对阵公布后，双方进入自己的桌次并完成准备。已就绪桌可按赛程开始，不因其他桌迟到而整体停等。
2. 迟到从该桌公布的报到截止时刻起计算，不从对手任意发起呼叫的时刻计算。主办方必须提供可核验的通知与时间记录。
3. 迟到宽限为`*`分钟；宽限内到场的处理为`*`，超过宽限的处理为`*`。处罚按单局还是整场计为`*`，不能混用。
4. 双方均缺席的结果为`*`；连续缺席`*`轮后的参赛资格处理为`*`。轮空不记为对手迟到或违规。
5. 平台故障导致无法进入桌次的，不直接按个人迟到处罚，由裁判核对服务与连接记录。

## 四、计时、断线与暂停

1. 本赛事五项计时分别为：玩家总用时`*`分钟、单次操作`*`分钟、断线宽限`*`分钟、天灾选择`*`分钟、起手选择`*`分钟。比赛中以服务器计时为准，不以某一客户端动画结束时刻为准。
2. 个人断线后应尽快重连并告知裁判。单次断线、累计断线和超时的裁定方式分别为`*`；断线不自动赋予无限等待或重赛资格。
3. 玩家提出规则疑问时应停止新的争议操作并呼叫裁判；是否暂停该桌、谁可暂停、恢复方式为`*`。不得自行以断线充当暂停。
4. 裁判可对经核实的平台异常补时；补时原因、时长及影响桌次须记录。不能只调整页面显示的倒计时。
5. 暂停赛事后续轮次与暂停某一桌是不同操作。线上现有“暂停赛事推进”不会自动停止已经进行的对局计时，不得向玩家作相反承诺。
6. 平台整体故障时，主办方应公告受影响范围和处理方式；不能把全站异常统一归为玩家超时。

## 五、弃权、退赛与成绩

1. 玩家可明确认输当前对局，也可申请退出剩余赛事；两者必须区分。退出赛事不等于自动撤销此前成绩。
2. 认输须由本人明确确认，不以沉默或未读消息代替。认输一经有效记录，该局结果为对手获胜；是否允许撤销误操作以及证据条件为`*`。
3. 整场弃权、退赛与取消资格的积分和排名处理为`*`。已完成成绩是否保留、对后续对手积分的影响为`*`；不得临时依据个人关系处理。
4. 工作人员移除正在进行的参赛者前，应确认理由和比赛状态。目前线上对未完成桌会给对手记录胜场，不能将移除操作当作无损编辑名单。
5. 比赛结果以经核验的对局结果和裁判裁定为准。玩家发现成绩错误，应在`*`分钟内报告；更正须保留原结果、理由与裁定人，不能无痕覆盖。
6. 未确认的争议成绩是否允许推进下一轮为`*`；最终成绩确认与奖项发放时间为`*`。

## 六、重赛与恢复

1. 先尝试恢复已有对局。正常断线重连或服务恢复不是新对局，不重抽起手、不重选先后手、不替换已锁牌库。
2. 重赛仅用于无法可靠恢复、且已严重影响公平的情况，不能因手牌不利、操作失误或一般规则理解错误要求重赛。
3. 重赛批准人为`*`。裁判应核对可恢复状态、错误原因、双方已知信息及故障影响范围，记录为什么不能继续原局。
4. 重赛范围为单局还是整场、先后手如何确定、双方剩余计时如何处理、是否重选起手与天灾，分别为`*`、`*`、`*`、`*`。原局必须明确标记作废，不得原局与重赛同时计分。
5. 故意制造故障、弃线以获得重赛或重新起手的，按作弊处理。证据不足时不得仅凭对手指控认定故意。

## 七、违规与判罚

1. 区分操作失误、规则误解、平台错误和故意作弊。裁判按事实、影响及重复情况处理，不能把系统缺陷自动归责于玩家。
2. 可采用的处分包括提醒、警告、单局判负、整场判负和取消资格；各级适用条件与是否允许升级为`*`。具体处罚表如下，确认前不得作为已生效量罚表使用。

| 情况 | 裁定重点 | 待确认处分 |
| --- | --- | --- |
| 迟到、缺席 | 通知、截止时刻、平台可用性 | `*` |
| 非法构筑、未经许可换牌 | 锁定快照、实际牌表、是否明知 | `*` |
| 拖延、拒绝执行裁定 | 正常思考与故意拖延的区别 | `*` |
| 泄露或利用隐藏信息、未经许可指导 | 信息来源、利用行为、工作人员权限 | `*` |
| 冒名、串通、故意操纵结果或利用漏洞 | 可核验事实与主观故意证据 | `*` |
| 侮辱、骚扰、威胁 | 具体行为、严重程度、重复情况 | `*` |

3. 同类情形应采用同一标准。处罚记录包括事实、依据、处分、裁定人及申诉途径；对外说明不公开无关个人信息。
4. 取消资格与限制未来参赛是不同措施。禁赛期限、执行范围与复核方式为`*`，不以一次移除自动推导永久禁赛。
5. 回退操作的许可范围为`*`。已经获得额外隐藏信息时不能未经裁判许可直接重来；不得以本地页面操作替代权威状态修复。

## 八、裁判权限、回避与申诉

1. 裁判解释规则、核实状态并处理争议，不代替玩家作策略选择。裁判不得将特权视角看到的隐藏信息透露给参赛者或用于其他比赛。
2. 本场裁判实时视角、管理员回放可查看双方手牌及盖伏卡，以履行裁定职责；普通观战和公开回放仍遵守各自公开信息边界。
3. 裁判与案件一方有亲属、队伍、直接利益或其他可能影响公正的关系时，应主动回避，由另一名无冲突裁判处理。主裁判本人需回避时的替代负责人为`*`。
4. 玩家可向主裁判申诉。申诉期限为裁定告知后`*`分钟；提交发生时间、争议操作与可用证据即可，不要求玩家复述全部规则或反复填写无关表单。
5. 申诉期间是否暂停该桌、是否暂缓相关轮次及最长等待时间为`*`。工作人员应说明当前处理状态，不能无限期挂起。
6. 主裁判复核事实与规则后作最终赛事裁定，告知理由并记录。进一步复核渠道、受理期限和权限为`*`。平台Bug反馈不自动推翻已确认的赛事裁定。

## 九、延期、取消与公告

1. 因整体平台故障、重大规则错误或不可抗力不能继续时，主办方公布延期或取消决定、受影响范围和后续安排。
2. 延期后的时间、牌库锁定是否继续、已完成成绩是否保留为`*`；取消时的排名、奖项、费用处理为`*`。
3. 赛中不得无公告地变更赛制、计分或判罚。必要例外须说明理由，并向所有受影响玩家一致告知。

## 十、确认清单与上线边界（内部审阅）

发布前需确认：赛制/局制/积分与同分顺序；签到和候补；备选区/换牌及牌表公开；迟到和缺席；五项计时、断线和桌次暂停；认输撤销、退赛成绩；重赛条件及恢复参数；判罚表/禁赛；成绩复核和申诉；延期取消。

已核对的现有流程：报名不交牌库，签到权威校验并锁定；开赛以已签到人数为准；新赛事使用同源五项计时并支持恢复；移除参赛者可影响未完成桌赛果；补时与暂停后续轮次不同；创建规则版本/哈希及牌库来源快照；结果幂等回填及权限边界。依据为`docs/TOURNAMENT-CENTER-CLOSEOUT.md`、`platform.ts:RankedTimeControlConfig`及用户已确认的裁判/管理员隐藏信息权限。

当前同源默认五项时长为25/4/4/1/1分钟，仅用于核对实现，不自动填作所有赛事必须采用的时限。实际采用值以赛事配置和最终公告为准。

候补、完整判罚/申诉工作流、重赛审批及桌次暂停等条款必须另做产品能力核验；有规程文字不等于线上已经提供对应操作。本草案不修改线上配置、不设维护、不发布资讯或规则内容。

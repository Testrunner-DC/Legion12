# 规则书术语、词条与职介能力清单

更新日期：2026-09-02

## 1. 使用边界

本清单是卡效原子化的术语基线，来源优先级如下：

1. 《十二军团》规则书 2.0 结构化文本；
2. 规则书 FAQ；
3. 设计者在项目对话中的明确裁定；
4. 卡面原文。

卡牌只引用公共词条或职介能力，不复制另一套规则正文。未列入本清单、或来源仍待确认的术语，不得仅凭卡名、卡号或 `EffectText.Contains` 推断实战规则。

## 2. 规则书的五种效果类型

| 类型 | 规则书定义摘要 | 是否可响应 | 原子执行模型 |
| --- | --- | --- | --- |
| 规则效果 | 以“规则上，……”描述，调整基本规则；无论卡牌是否在场均一直生效 | 否 | `rule` / replacement |
| 持续效果 | 条件符合期间静态生效 | 否 | `continuous` |
| 主动式效果 | 由玩家主动发动，满足条件并支付费用后获得效果 | 发动动作可进入响应流程 | `activated` |
| 触发式效果 | 符合条件时发动；含“可”时控制者选择是否发动 | 是 | `triggered` |
| 反应式效果 | 只在特定响应时机发动 | 是 | `reaction` |

补充约束：

- 未写“可”的触发效果为必发，能处理的部分应尽可能处理。
- “登场时”在打出到场上时触发；规则书 2.0 明确其触发源通常在效果结算后才完成登场动作。
- “……后”在触发源动作完成后发动。
- 规则效果与持续效果没有“发动”动作，不能被响应。
- 天灾为特殊触发式效果：等待当前全部堆叠处理完毕后触发；天灾不能被响应，也不会触发其他卡牌的登场时、离场时或阵亡时效果。

## 3. 规则书“词条一览”

规则书说明：词条以白底黑字异形框标注，同名词条不可叠加。

| 词条 | 类型 | 规则书定义 | 公共引用 |
| --- | --- | --- | --- |
| 强攻 | 触发式 | 此军团因进攻对主宰造成伤害时，额外再造成1点伤害 | `strong-attack` |
| 免死 | 触发式 | 仅1次，即将阵亡时，让此军团的兵力在本回合变为1000作为代替；获得时可放置免死指示物，发动后移除 | `survive-once`（待完成公共运行时） |
| 必中 | 持续 | 此军团进攻时，对方无法进行抵挡或支援 | `sure-hit`（待完成公共运行时） |
| 挑衅 | 持续 | 对方只可进攻拥有挑衅的军团；存在多个时可任选其中1个 | `taunt` |
| 冲锋 | 持续 | 在登场的回合即可进行进攻 | `charge` |
| 隐匿 | 主动式 | 发动后将此军团翻转；覆盖时不能成为效果或进攻目标；我方主要阶段可再发动隐匿将其翻回正面。覆盖卡只有“1张卡”的属性，不视为军团，但占据战场位置，且不能被打出的军团或覆盖反击战术顶替 | `conceal`（旧分支已具备，待完全公共化） |
| 震击 | 触发式 | 进攻时触发，被进攻者左右相邻的军团本回合兵力-2000；连带阵亡保留来源击杀，但不触发印刷【击杀时】 | `shock` |
| 贯穿 | 触发式 | 击杀时触发，在进攻军团后，以此军团剩余兵力对对方主宰发动1次进攻；此次进攻不触发“进攻时”效果 | `piercing` |

注意：免死是替代即将阵亡的效果，不是先阵亡、再复活；其“本回合兵力变为1000”属于设定值层。

## 4. 职介、攻击方式与职介能力

规则书把近战、远程定义为攻击范围分类；职介本身用于被其他效果引用。职介能力必须与词条分开建模。

### 4.1 规则书基础攻击范围

| 攻击方式 | 所在位置 | 合法目标 | 是否远程进攻无损 |
| --- | --- | --- | --- |
| 近战 | 我方前排 | 对方前排、对方主宰 | 否 |
| 远程 | 我方后排 | 对方前排 | 是 |
| 远程 | 我方前排 | 对方前排、后排、主宰 | 只有进攻对方后排时属于远程进攻无损；进攻前排时仍会损失兵力 |

### 4.2 已确认的职介能力

| 职介 | 已确认公共能力 | 来源 | 内核规则 |
| --- | --- | --- | --- |
| 弓手 | 进攻距离+1，远程进攻无损 | 设计者 2026-08-26 明确裁定 | 印刷或派生“视为【弓手】”后，统一由派生职介查询赋予，不再按卡号重复登记 |

以下内容不能自动泛化：

- 卡面写有“进攻距离+1，远程进攻无损”不等于该军团自动视为【弓手】。
- “位于前排/后排视为某职介”是条件派生职介，离开该位置后立即重算。
- 术师、刺客、骑兵等是否具有阵营外的统一职介能力，需以规则书或设计者逐项确认；不得仅因多张卡文本相似自动赋予。

## 5. 核心概念与规则动作

这些不是词条，但会决定原子的合法性、区域移动、持续时间与结算结果。

| 概念 | 权威语义 | 原子化要求 |
| --- | --- | --- |
| 黄金规则 | 卡面与规则文本冲突时以卡面为准 | 卡面特例应覆盖公共默认值，但不能绕开规则时点 |
| 支付费用 | 1张活跃士气转为休整即支付1点；冒号前全部费用必须能完整支付 | 目标/模式预声明后统一校验，再原子支付 |
| 兵力值 | 受到等于或超过当前兵力的伤害时阵亡；兵力降至0或以下也立即阵亡 | 任何派生数值重算后执行0兵力状态检查 |
| 击杀时 | 军团通过战斗击杀军团时触发 | 必须绑定本次交战结果，不把效果击杀算作战斗击杀 |
| 阵亡时 | 因战斗、效果或规则阵亡并置入墓地时触发；支援阵亡可触发；天灾不触发 | “弃置”“放回”“移出”不等于阵亡 |
| 活跃/休整 | 活跃为竖直；转为休整时顺时针旋转90°；休整卡不能再次转为休整 | 状态是费用和行动合法性的独立字段 |
| 登场失调 | 军团登场回合不能进攻 | 冲锋或明确“本回合可进攻”才覆盖该限制 |
| 场上 | 双方战场、圣物区、士气区、阵营专属放置区及主宰卡 | 区域查询不能只扫描六格战场 |
| 战场位置 | 前后排各3格；正面卡不能被通常打出顶替；可顶替己方覆盖战术 | 选位必须使用棋盘合法目标，不用编号弹框 |
| 位移1格 | 向前、后、左、右相邻空位移动，不能越过卡牌 | 与“1次位移”分开 |
| 1次位移 | 移到己方战场任意空位，可以越过卡牌 | 骑兵位移等能力引用此规则时单独显示按钮 |
| 否定优先 | “不能/无法”始终优先于允许该动作的效果 | 合法动作查询先应用禁止规则 |
| 查看 | 仅指定玩家查看非公开信息 | 不写公开日志中的具体卡名 |
| 展示 | 将指定卡面朝上给所有玩家查看 | 战场中央无蒙版展示卡图3秒，并记录可查询卡名 |
| 弃牌 | 通常由需要弃牌的玩家从手牌选择；随机弃牌由对方随机抽取 | 置入所有者墓地，但不触发阵亡时 |
| 致命替代 | 在“即将阵亡”时用其他卡或资源承接结果；不是原军团先离场再复活 | 战场代替卡承接原致命动作的目的区与事件；卡面明写从手牌弃置时只执行手牌弃牌事务 |
| 控制者/所有者 | 所有权不变，控制权可变；“我方/对方”指当前控制者；卡牌不能进入非所有者的手牌、牌库或墓地 | 所有离场去向按所有者解析 |
| 衍生卡/指示物 | 所有者为创造者；离场时消灭，不进入其他区域 | 不得把衍生卡加入墓地或牌库 |
| 返还士气 | 活跃或休整士气均可返还 | 需要区分资源身份/状态时由玩家点击场面选择 |

## 6. 不可混用的相近概念

| 概念 A | 概念 B | 区别 |
| --- | --- | --- |
| 词条 | 职介能力 | 词条是具名卡牌效果；职介能力来自当前印刷/派生职介 |
| 远程 | 弓手 | 远程是攻击方式；弓手会获得远程能力，但拥有远程文本不反推弓手职介 |
| 登场失调 | 冲锋 | 前者为默认限制，后者允许登场回合进攻 |
| 位移1格 | 1次位移 | 前者相邻且不能跨牌，后者任意空位且可以跨牌 |
| 击杀时 | 阵亡时 | 前者要求战斗击杀；后者覆盖战斗、效果或规则阵亡 |
| 展示 | 查看 | 展示对所有玩家公开，查看只向指定玩家公开 |
| 弃置 | 阵亡 | 弃置是区域移动，阵亡是会触发阵亡时的规则结果 |
| 战场致命替代 | 手牌弃置替代 | 前者的代替卡承接真实阵亡/离场/所有者目的区；后者只产生弃牌事件，不伪造战场阵亡 |
| 进攻无损 | 远程进攻无损 | 前者适用于该次进攻本身；后者只在进攻构成远程进攻时生效 |

## 7. 待确认或待公共化事项

1. 术师、刺客、骑兵等职介是否有不依赖卡面重复文本的全局通用能力，继续等待规则书或设计者裁定。
2. `免死`、`必中`、`隐匿`、`震击`、`贯穿` 已有实战路径，但需继续收束为后台与实战共用的唯一公共定义。
3. 原子运行时只接受本清单中的稳定引用；中文词条解析只可用于审计提示，不能作为实战判定来源。

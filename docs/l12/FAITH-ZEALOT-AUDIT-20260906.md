## 2. 卡面原文与解释边界

`S02-0006` 〈信仰狂热者〉完整卡面：

```text
<信仰狂热者>的效果每回合只可使用1次。
我方回合 此军团从牌库弃置或因效果从手牌弃置时：可无视消耗触发1次我方需要消耗士气的主宰效果，且不计入主宰效果使用次数。
```

本次采用以下一致口径：

1. “需要消耗士气”只匹配卡面明确写作“消耗士气”的主宰效果；“返还士气”“翻转士气/神力”“消耗神力”“消耗符文”和主动休整不是同义词，不纳入。
2. 一旦某项主宰效果因“消耗士气”符合条件，“无视消耗”覆盖该项效果的全部费用，而不只覆盖士气。例：梅杰德的额外休整陵墓守卫、瓦尔基里的主宰自伤、洛基治疗模式的墓地回牌、荷鲁斯的两张战场弃置均不支付。
3. 冒号后的效果步骤与持续后果不是费用，继续执行。例：洛基抽牌模式仍需在抽牌后弃置1张手牌；索尔发动后仍获得“本局无法因效果增加血量”。
4. 目标、位置、区域、兵力/费用阈值和状态条件继续检查。免费不等于忽略合法性。
5. 只能在别的事件已建立的触发时点发动、且依赖那次事件对象的能力，不凭空制造参照。月读需要“刚位移的军团”，迦具土需要“正在进攻/被进攻的军团”，因此不在信仰狂热者的独立选择中。
6. “返还士气”在卡表、费用登记、事件记录和临时士气规则中均为独立动作；临时士气不是可返还的实体士气。因此杨戬第二能力、孟婆第一能力、孙悟空、嫦娥等均不因出现“士气”二字而符合。
7. 既存实现若过去曾允许一个无法重建时点参照的能力，本次不会为了兼容而伪造对象；公开选项以本表的卡面判定为准。
8. 触发来源严格按卡面：只在该卡控制者的我方回合检查；从牌库弃置不区分效果或费用，从手牌弃置则必须是“因效果”，冒号前支付的弃牌不触发。回合1次按物理实例 ID 记录，两张同名实体各自拥有一次。

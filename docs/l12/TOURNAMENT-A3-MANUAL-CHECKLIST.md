## 未通过 / 需要决定的发现

### 1. 非参赛账号没有观战入口（A3 第 1 项的直接阻塞）
用**非参赛**账号 `彩排01` 打开同一场 `public` 赛事，赛程页只显示「第 1 桌 彩排07 vs 彩排08 进行中」，**没有任何「观战」按钮**（`getByRole('button',{name:'观战'})` 计数 0）；而参赛者 `彩排07` 的同一行同时有「进入对局」与「观战」。
→ 也就是说「观战隐藏手牌」这条剧本，用"第三个非参赛窗口"根本无法按原剧本执行；观战的 UI 入口目前只出现在参赛者/裁判台视图。
需要决定：① 观战本就只对参赛者与裁判开放（则剧本改为用裁判台验证，A3 通过）；② 或 public 赛事本应对任何人开放观战（则是缺口，需补入口）。

### 2. 账号进过房间后，赛程行不再给「进入对局」（影响复测）
同一账号第二次打开赛程时，行内不再出现「进入对局」（会话仍绑定在该房间），脚本必须改为「返回对局/继续」路径。这不是缺陷，但会让人工复测反复困惑，建议这类行文案在房间存在时明确写「回到对局」。

### 3. 手牌断言的前置条件（供后续复测）
进房后先「等待对手」；对手进入后由**赢得先后手的一方选择先攻/后攻**，选择完成、抽牌阶段开始后才渲染手牌区域。此前两次断言失败都是**在选先后手之前**取值（`[data-l12-zone="hand"]` 存在但 `.hand-card-wrap` 为 0），不是手牌泄露。

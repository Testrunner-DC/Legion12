# Bug 同类扫描矩阵

| 问题类型 | 必查范围 | 最低回归保护 |
| --- | --- | --- |
| 士气/额外费用 | 打出、覆盖反击战术、位移、主动效果、效果结算、临时士气、特殊支付物 | 每条支付入口测试 + 精确资源选择测试 |
| 主动/触发/响应效果 | 主宰、阵营、军团、圣物、试炼、特殊区域 | 服务端逐能力可用状态 + 前端禁用契约 |
| 目标选择 | 手牌、牌库、墓地、战场格、主宰、特殊区域 | 预声明与结算前复验 |
| 卡图 | S1/S2 查询数据、服务端目录、静态文件、横竖版展示 | 全卡池资源审计脚本 |
| 卡牌分类 | 卡牌查询、牌库编辑、合法性、预组、对战区域 | 全卡池分类断言 |
| 补充文本/衍生卡 | 查询详情、对战详情、日志来源、专属衍生卡 | 统一关联数据测试 |
| 可点击且可查看元素 | 主宰、阵营、军团、圣物、墓地、特殊区域、Prompt 卡牌 | 点击动作与 hover/focus 详情同时存在的 UI 契约 |
| 双面/异画同类卡 | 正反面卡号、分类、构筑、士气/特殊区域镜像、消耗、翻面 | 每个卡号的数据断言 + 公共运行时行为测试 |
| 持续/静态兵力 | 回合方、位置、相邻、阵营、叠加来源、快照重算、战斗前后 | `DerivedStats` 理论测试 + 完整进攻/响应不重复测试 |
| 状态式阵亡 | 战斗、效果减兵、持续减兵、设定兵力、入场减兵、天灾 | 每个成功命令后的统一检查 + 天灾抑制触发测试 |
| 离场状态重置 | 军团、圣物、反击战术、叠放卡；墓地/手牌/牌库/移出 | 公共重置函数 + 墓地状态断言 + 直接写区扫描 |
| 军团支援 | 同列后排、兵力合计、必中、不能支援、无合法候选 | 有候选保留窗口 + 无候选自动结算 |
| 动态打出费用 | 自伤减费、免费战术、符文、阵营/主宰、天灾、持续修正 | 服务端 `playCost` 快照 + 前端角标/高亮契约 |
| 日志与效果选项 | 长文本、卡名链接、协议 ID/展示文案、横纵布局 | 换行容器契约 + 纯效果纵向按钮契约 |
| 伤害来源 | 进攻、己方效果、对方效果、天灾/规则中立来源、自伤费用 | 显式来源控制者 + 中立来源测试 + 禁止按回合方推断 |
| 同时选择/同时结算 | 双方弃牌、抽弃、并行排序、同时支付 | 双方选择先锁定，最后回答后原子提交；第一方回答后状态不变测试 |
| 离场原因 | 阵亡、弃置、置入墓地、回手、回牌库、移出 | 显式离场类型 + 阵亡专用触发/免死隔离测试 |
| 效果无效化 | 目标、模式、卡牌、位置及资源选择 Prompt | 以 `StackItemId` 清除从属 Prompt；登场与已支付动作不回滚 |
| 墓地卡牌选择 | 回手、回顶/回底、登场、费用、排序及不可进牌库替代 | 具体实例选择 + 合法区域校验 + 禁止无文本依据的 `Take(n)` |

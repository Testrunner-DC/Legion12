## 一、目标与非目标

### 总目标

证明同一局游戏经历长命令链、多个检查点、Journal 重建和不同接收者读取后，仍只有一套权威结果：

1. 不中断执行、检查点恢复执行和 Journal 回放执行产生相同的权威状态与随机流；
2. 错误、重复、延迟、乱序和过期请求至多生效一次，被拒请求不留下状态、事件或 Journal 副作用；
3. 玩家甲、玩家乙、观战者和裁判只看到各自被授权的信息，断线、恢复和回放不会补泄露历史私密信息；
4. 长局状态、投影、Journal 和恢复耗时保持有界，不随重复恢复产生异常膨胀。

### 非目标

- 不做 324 张卡、所有卡位和所有命令顺序的指数级笛卡尔积；
- 不以新规则反算旧版本回放，不绕过 Journal V2 或接收者投影端口；
- 不把引擎检查点恢复等同真实 WebSocket 断线重连；两者分别进入不同批次；
- 发现红灯时不在测试批内顺手修改产品规则。先保留最小复现、同类扫描和修复建议，按 Bug 流程取得用户批准后另开有界修复批；
- 任一批均不自动部署。

## 三、统一对抗模型

每个场景维护三条执行线：

- **A 不中断线**：从初态连续执行完整命令链；
- **B 恢复线**：在指定切点序列化并重建引擎，再继续执行相同命令；
- **C 回放线**：通过真实 Journal V2 检查点和命令记录重建，不用测试专用影子状态代替。

### 每个有效步骤的比较项

| 类别 | 比较内容 |
| --- | --- |
| 权威状态 | `SerializeFullState()`、`ComputeStateHash()`、随机状态、Revision、当前回合与行动玩家 |
| 流程状态 | Pending Prompt、Pending Activation、响应栈、同时触发排序、使用次数和已支付费用 |
| 事实与事件 | CardFact 序列、稳定能力身份、公开事件序列、Prompt 审计和命令接受结果 |
| 接收者投影 | 玩家甲、玩家乙、观战者、裁判各自的完整授权投影 |
| 持久化 | 检查点序号、Journal 命令顺序、请求去重状态和每步状态哈希 |

接收者投影按“各自授权域内一致”判断，不要求不同角色看到相同内容。私密字段使用结构化权限断言和专用哨兵实例验证，不能只靠模糊文本搜索。

### 必须覆盖的恢复切点

1. Prompt 创建前与创建后；
2. 费用支付后、效果结算前；
3. 嵌套响应栈中；
4. 来源离场或最后已知状态冻结后；
5. 目标声明后失效时；
6. 私密检索、查看、洗牌或牌序调整期间；
7. 同时触发排序过程中；
8. Journal 尾部截断、重复帧或校验失败时的失败关闭。

## 六、第一批 LC-01 详细规划

### 批次名称

`LC-01｜长链合同冻结与最小确定性驱动器`

### 开工前置

LC-01 实施前重新向 L12-main 请求状态快照和风险裁定。至少确认：主线提交、工作树、在途写入、测试文件租约、现有帮助器是否变化、当前完整规则数量和门禁预算。

### 分目标

#### LC-01-G1：冻结比较合同

- 把 A/B/C 每步必须比较的字段固化为具名合同；
- 区分“角色内恢复一致”与“角色间权限不同”，避免把隐私裁剪误判成状态分叉；
- 明确拒绝命令允许返回错误响应，但不得改变权威状态、Revision、事件、审计、Journal或投影。

#### LC-01-G2：建立可复现的场景描述

场景必须包含：场景 ID、焦点卡号、风险族、种子、初始状态来源、命令序列、恢复切点、接收者检查点和预期拒绝项。失败输出至少包含：

- 首个不同的步骤与字段路径；
- A/B/C 三线哈希；
- 最小命令前缀；
- 种子、切点和焦点卡号；
- 四类接收者的投影差异摘要。

同一失败必须能用单个测试或单个场景 ID 重放，不依赖再次随机命中。

#### LC-01-G3：实现最小 A/B/C 驱动器

- A 使用现有引擎命令入口；
- B 使用当前版本检查点与完整随机状态恢复；
- C 使用真实 Journal V2 记录和重建入口；
- 不创建第二套状态机、JSON 补丁回放器或测试专用规则解释器。

#### LC-01-G4：建立四接收者投影矩阵

每个比较点生成玩家甲、玩家乙、观战者和裁判投影；使用结构化授权规则验证手牌、盖伏牌、私下查看、检索候选、私密 Prompt 和私密选择结果。

#### LC-01-G5：代表场景清单

第一批至少覆盖以下六类，各类至少一条完整链，允许同一场景同时承担多个类别：

1. 叠放、转移与最后已知状态；
2. 限时修正和持续效果来源失效；
3. 响应堆叠、无效与同时触发排序；
4. 私密手牌、牌库检索、查看和牌序变化；
5. 天灾与试炼进度；
6. 跨回合清理、使用次数或致命替代。

上一批发生恢复分叉的 15 张卡必须全部进入 LC-01 短链：韩信、关羽、图特摩斯三世、阿伊、贝奥武夫、古斯塔夫一世、珀洛特埃、汉尼拔、彭忒西勒亚、斯巴达勇士、亚瑟王、帕西瓦尔、高文、斯卡哈、吉原的花魁。

#### LC-01-G6：拒绝与至多一次语义

在代表链中插入错误玩家、重复、延迟、乱序和过期请求。引擎级错误与房间级请求 ID 分开记录；第一批可复用已有房间帮助器验证代表路径，但不宣称完成真实 WebSocket 断线竞态。

## 防回滚要求

- 后台原子组合、卡牌详情和实战执行必须读取同一份结构化能力定义。
- 条件职介、条件兵力设定、距离与远程无损不得再按页面或卡号各写一份。
- “最多 X 张”统一允许 0..X；“选择 X 张”才是强制 X。
- 响应窗口不得根据玩家是否持有合法牌改变是否出现；新响应入栈后必须交还优先权。
- 场上卡离开时以 `OwnerIndex` 决定私有区域，以战场位置决定当前控制者；两者不得混用。
- 每次修复前查询 `docs/BUGFIX-REGISTRY.md`，完成后记录根因、同类扫描、回归与防回滚约束。

# 十二军团连续引导教学建设方案

教学要让玩家理解自己为什么行动，而不只是完成指定动作。入口仍使用原“单人”位置；点击“教学”立即进入主线，不再增加“进入教学目录”的中转按钮。整套教学验收完成前仅在测试服开放，正式服保持不动，沙盒仍只允许管理员从后台进入。

## 主线结构

旧八项内容作为知识覆盖清单，不再按单个动作拆成八个关卡。主线合为三个完整章节，每章内部用对话、图示、真实操作、结果解释和复盘连贯推进。

| 章节 | 玩家要理解的内容 | 实际操作 |
| --- | --- | --- |
| 初识十二军团 | 获胜目标，主宰、军团、战术、圣物和士气，费用／兵力／卡牌效果，活跃与休整，前后排 | 打出军团、支付士气、普通移动、进攻主宰、抵挡或不抵挡 |
| 卡牌效果与响应 | 卡的发动与效果的发动，费用与效果，选目标，堆叠与响应，取消与不能退回的支付 | 发动军团效果，打出战术，用已盖伏的反击战术响应，比较无效后的结果 |
| 完成一场对局 | 准备与天灾禁选／确认，回合流程，基本构筑，独立判断与胜负 | 使用合法预组完成有引导的小局，再逐步撤去提示 |

第一章不要求背全规则。先说明“让对方主宰血量降至0即可获胜，同时保护己方主宰”，其他败北条件和例外按后续情境解释。卡牌种类先用真实卡图和简短对话建立认识，进场后再指向实际位置和数值。

## 先理解来源和收益

每个知识点都回答“这是什么、从哪里来、为什么要用、付出什么、得到什么、如何补充”。高亮箭头只负责定位，不能代替这些解释。

| 内容 | 来源与补充 | 用途与取舍 |
| --- | --- | --- |
| 手牌 | 标准准备的起始手牌来自牌库；通常己方抽牌阶段再抽1张，先攻首回合不抽，卡牌效果也可提供手牌 | 提供行动选择。打出和弃置会减少手牌，保留军团也可能用于抵挡；手牌多不代表费用足够 |
| 士气与费用 | 士气阶段从士气牌库追加活跃士气，通常2张、先攻首回合1张；重置阶段使可以重置的已有资源恢复活跃 | 将活跃士气转休整以支付费用。追加新士气和恢复已休整士气分别讲，不能把支付解释为永久删除资源 |
| 场上军团 | 从手牌合法打出，或由卡牌效果使其登场 | 付出手牌与费用，换取进攻、防守、站位和卡牌效果；新登场通常不能立刻进攻，不能许诺即时收益 |
| 移动与位置 | 普通移动使用当前军团与合法相邻空位 | 付出费用换站位和后续攻防机会，不会因为移动就自动增加兵力 |
| 进攻与防守 | 根据当前活跃状态、位置、兵力和合法目标决定 | 进攻逼近获胜目标，防守保护主宰或军团；代价和结果都依本次真实场面说明，不固定推荐永远进攻或永远抵挡 |

抽牌、士气追加和重置不仅在概念页说明，进入战场后还要指向牌库、手牌、士气牌库与士气区；交接回合时，用真实新增牌、资源和状态变化解释补充过程。每段操作结束先说明实际获得和付出，再回到主线。

## 对话和主线衔接

引导框有稳定的向导身份、当前讲解、一处明确目标和可选择的回答。说明步骤由玩家点击“继续主线”，不按时间自动翻页；操作步骤等待原界面的真实结果，再讲解发生了什么。

每个知识点允许在原框内选择“我想了解……”查看补充解释，随后用“明白了，回到主线”回到原步骤，不切路由、不退出当前场面。每段实操结束后先复盘，再在引导框里继续下一段。只有整章讲解、实操和复盘都完成，才显示本章完成。

本机学习进度独立版本化并按账号隔离。旧版三个动作的完成记录保留，但不能自动当作新版教学已学完。断线、切号、迟到回复、失败保存和重学都不能错误推进其他账号或下一场景。

## 打出第一张军团的逐步脚本

1. 向导介绍本次要打出的军团，高亮真实手牌中的那一张卡，箭头指向它；先认识卡名、兵力和效果，不立即要求操作。
2. 展示该卡费用的位置，解释“费用”不是“兵力”。费用从当前卡牌投影读取，不用固定数字覆盖减费等真实状态。
3. 高亮士气区，说明本方当前有多少活跃士气、哪些可用于支付；数值使用当前公开投影。解释“将活跃士气转为休整以支付费用”。
4. 提示玩家选择这张军团。移动端若需要先点“打出”，单独指向实际按钮，不假设与桌面一步相同。
5. 指向当前合法的空阵地，说明前排、后排和本次要放的位置；合法位置仍由原界面和服务器决定。
6. 原支付询问出现后，高亮支付对象和确认按钮，解释需要支付多少。不能在没有询问时指向一个不存在的按钮。
7. 等待服务器已提交的军团登场和士气变化，再解释“手牌减少、军团登场、士气休整”及当前真实数值；未成功不能提前显示结果。
8. 向导总结本次过程，提供补充问答和“继续主线”。不是收到一次动作成功就给出“你已学会”的结论。

普通移动和攻防遵循相同分层：先说明条件和代价，再逐项指向军团、按钮、合法位置或主宰，最后解释兵力、血量、活跃／休整和抵挡结果。移动保持真实的“选择军团→普通移动→相邻空格→按提示付款”顺序。

## 术语与展示

- 使用主宰、军团、战术、圣物、士气、兵力、费用、打出、登场、活跃、休整、进攻、抵挡、支援、盖伏、发动效果、响应和堆叠；不套用其他游戏的召唤、部署、法力等称呼。
- “打出军团”描述玩家行动，“军团登场”描述结果；卡的发动和效果的发动不能混为一谈。
- 以当前正式规则和卡牌文本为来源，教学解释不能改写卡效、支付、移动或进攻限制。阵营和卡牌例外在相应情境说明。
- 高亮和箭头绑定真实可见DOM对象，随桌面、逻辑横画布、竖屏、滚动和弹框变化，不用固定屏幕坐标。目标不可见时先提示展开对应区域，不把箭头指向屏外。
- 引导框不能压住当前要按的卡牌、支付或确认按钮；聚焦层不截获这些真实输入。不为教学增加常驻全站轮询。

## 实现边界

保留P0—P4：同一规则内核、接收者投影和Journal，不增加教学专用规则计算、GM权限或客户端局面写入。初版三个合法内部场景可作为第一章的连续练习素材，但界面不再把它们展示为三个关卡；内部切换必须先收到真实离房确认，再创建下一场景，并说明这是下一段练习的新场面，不能伪称刚才的操作改变了该场面。

游戏结果和学习进度分别处理。服务器的completed仅代表本段动作条件完成；学习完成还需要本段讲解和结果复盘。二者同时成立，才允许主线继续。补充问答只控制讲解，不伪造服务器动作或结算。

账号切换、连接代际变化或新房间占用会取消待续接操作；不让旧回执自动带另一个账号进入教学。离房等待期间只显示等待与退出入口，不因计时到达便假定已离房。网络与保存失败提供明确重试，保留原费用、取消和维护限制。

## 验收与发布

1. 先核术语、逐步脚本和真实按钮顺序，再冻结候选，不把动作脚本通过当成教学体验通过。
2. 桌面1366×768、短横屏844×390和竖屏390×844实际走完“入口→目标与卡牌→打出与费用→移动→攻防→章末复盘”，全程不进入二级目录。
3. 每一步检查目标高亮、箭头端点、当前数值、可见性、触摸命中、问答返回位置和真实结果。问答不能跳过未完成操作，动作成功不能跳过尚未讲解的结果。
4. 覆盖拒绝、重复、断线、账号ABA、房间切换、保存失败、重学和旧版进度兼容；保留沙盒权限、原观战、普通对局和统计隔离回归。
5. 受影响检查与完整发布验收通过后才更新测试服，独立读回版本和入口。三章全部验收前禁止正式发布，不改变正式维护或运营配置。

## 当前状态

测试服最后核验的c9版本是旧三段动作练习，只作为可复用的规则与权限底座，不代表本方案的教学质量已通过。第一章连续对话、直接入口、逐步聚焦箭头和复盘续接已在本地三尺寸完整实操验收，完整前端批次通过。干净发布检查有一例大房间准备指令被拒绝，尚未确定原因，因此没有更新测试服；后续单类通过不替代整轮失败。真实卡面像素仍需在实际测试站点核验，本地操作验收不替代该项。

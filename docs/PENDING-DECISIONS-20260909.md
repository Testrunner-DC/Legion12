## 2. 方案已经可以讲清楚的待确认项目

### R3 《草薙剑》不能把“没有费用”当成“费用为0”

已确认规则：《哮天犬·稚》没有费用维度。这个裁定不需要再确认。

问题例子：《草薙剑》击杀“费用不高于2”的军团。真正0费军团满足条件；没有费用的《哮天犬·稚》不应因为程序用0作为默认值而被选中。本次看到初选代码仍直接比较CurrentCost <= 2，这构成需要核对的具体入口，但不等于已完整复现原对局。

建议改法：费用阈值查询先判断对象有无费用，再比较数值；把候选显示、提交与结算的判定统一。扫描同类费用查询时逐项遵守已有裁定，不让“无费用”自动变成不能被击杀、不能战斗或不能受兵力效果影响。

验收：无费用对象排除；真正0费对象仍合法；2费/3费边界和合法减费后结果正确；选择后状态变化、重连不改变规则。

你需要决定：是否同意按这个边界修复费用查询。无需再次确认《哮天犬·稚》有没有费用。

### R4 《黯陨晨星》免费主动战术：先核实分支，不能凭报告文字定性

玩家反馈：使用《天诛》仍被扣费，报告把免费分支写成“双数”。

当前卡文：双数休整1张活跃士气；单数可以选择“打出主动战术无需消耗费用”，或选择后排术师/弓手进攻主宰。

必须区分：
1. 实际掷出单数，且选择免费，仍扣除打出费用：应修复。
2. 掷出双数，或单数选的是另一分支：不应自动获得免费。
3. 被支付的是卡文内部另列的代价：不能未经裁定一并免掉。

建议：重建实际骰点、所选分支、使用卡牌和扣除的费用类别。若属于第一种，让费用提示和实际结算统一读取当回合免费状态。

你现在无需改卡文；开发方先补证据，再把有证据的改法交你确认。玩家记错单双数也不是直接关闭报告的依据。

### R5 《关羽》的必中与“更换进攻目标”是否冲突

当前卡文的必中解释为进攻无法被抵挡/支援。
- 《空城计》明确执行抵挡：先核实当时必中是否已经成功获得并仍有效。若有效却成功抵挡，应按已有关键词规则处理。
- 《戏法师的傀儡》是休整登场并把进攻目标改为自身，动作不是抵挡或支援。

建议裁定：必中阻止抵挡/支援，但不额外阻止纯粹的目标更换；《戏法师的傀儡》仍需满足自己的登场位置等条件。

你需要决定：是否认可这一区分。未获裁定前不把两张卡都改成无法应对必中。

### U15 支付前可以重新选择，支付后不回滚Cost

玩家误选支付对象后希望回到上一步。

建议结果：尚未提交支付时允许“重新选择”，同时清掉依赖旧选择的后续目标。请求已发送、结果未确认时先锁定重复操作；服务器已经确认支付并发动后，不提供退回费用的撤销。断线回来以服务端确认状态为准。

例子：选错了要消耗的士气但还没确认，可以换；已经发动且对方正在响应，不能撤回以规避被无效的结果。

你需要决定：是否接受这个操作边界。实现要同时检查前后端，不能只加一个返回按钮。

### U16 只有一种实际支付结果时省略重复询问

普通士气看起来相同，不一定意味着支付后果相同。临时士气使用后消失、黑色莲花特殊属性、锁定状态、士气与陵墓守卫的选择，都可能留下不同局面。

建议：先复核现有等价候选代码。全部合法选择最终效果相同才自动处理；只要留场资源或后续规则影响不同，仍让玩家选择。只修已证明遗漏的入口。

已确认边界：士气返还之后不继续追踪其先前被锁的状态；这个裁定继续生效。

你需要决定：是否按上述标准补齐遗漏，而不是强制每次询问，或一律替玩家自动支付。

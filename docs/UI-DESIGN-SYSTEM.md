# Legion12 全局界面规范

## 适用边界

`opcgpro-vue/src/l12/site/uiSystem.css` 是普通站点页面的共享视觉基准，以主页和卡牌图鉴的深色、低圆角、金色主操作与青色信息提示为来源。它只在 `SiteShell` 内生效。

对战、回放和牌库编辑器是沉浸式画布，继续使用各自的逻辑画布与自适应尺寸令牌；不得从本规范继承会改变几何、卡牌比例或移动/宽屏隔离的规则。

## 共享令牌

- 页面、基础面板、抬升面板与输入控件分别使用 `--l12-ui-page`、`--l12-ui-panel`、`--l12-ui-panel-raised`、`--l12-ui-control`。
- 正文、次级文字、弱化文字分别使用 `--l12-ui-text`、`--l12-ui-text-soft`、`--l12-ui-text-muted`。
- 主操作使用 `--l12-ui-accent`；信息与焦点使用 `--l12-ui-info`；危险和成功状态使用对应语义色。
- 圆角只使用 small / medium / large 三档；面板和弹框阴影只使用共享阴影令牌。
- 页面级间距优先使用 `--l12-ui-space-1` 至 `--l12-ui-space-4`，避免新增无规律间距。

## 基础组件

- 输入框、选择框和文本框统一为深色底、灰色边线；键盘焦点为青色双层提示。
- 主要按钮为金色，危险按钮为暗红色；禁用状态保留可读文字，不通过纯透明隐藏。
- 普通弹框共用抬升面板、large 圆角和弹框阴影；窄屏改为底部安全区面板。
- 页面标题的英文眉题使用青色，正文仍使用共享中文黑体字族。
- 图片上传只显示一行建议比例，不显示格式、体积、像素校验或服务端实现说明。

## 单卡选择

`opcgpro-vue/src/l12/SingleCardPicker.vue` 是唯一的“选择一张卡”组件，提供卡名/编号/效果搜索以及类型、阵营、产品、费用、天灾等级筛选，并可查看卡牌详情。调用点：

1. GM 面板添加或打出卡牌；
2. 后台单卡数据分析；
3. 异画绑定原卡、直接派发、赛季派发和自动规则；
4. 运营构筑限制的单卡选择；
5. 沙盒自定天灾替换。

头像选择只选择允许作为头像的主宰展示版本，不属于规则或运营意义上的任意单卡选择；天灾池是多选组件，也不属于本组件范围。

## 防发散要求

- 新普通页面先复用共享令牌和现有面板/表单语义，不新增相近但不同的颜色、圆角与阴影。
- 新增“选择一张卡”入口必须复用 `SingleCardPicker`；多选或对局内合法目标选择不套用它。
- 修改共享规则后必须执行 UI 契约、类型检查和生产/测试路径构建，并复查窄屏横向溢出。

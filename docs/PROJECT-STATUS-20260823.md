## 1. 产品范围

项目当前同时承担十二军团官方主页、资讯与规则/FAQ、卡牌档案、牌库编辑与牌库广场、在线对战、单人测试沙盒、对局记录与回放、赛事中心、玩家账号以及管理后台。

移动端专项适配和管理后台的大规模扩展暂不进入当前批次；当前优先保证桌面端规则内核、全卡效、沙盒复现、网络恢复和内容发布链路稳定。

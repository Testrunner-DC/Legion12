# 账号邮箱与密码恢复运维配置

账号邮箱是可选能力。旧账号不需要邮箱即可继续使用用户名和原密码登录；只有已完成验证的邮箱可以发起忘记密码找回。

## SMTP 环境变量

服务端只读取环境变量，不在仓库、平台快照或日志中保存 SMTP 凭据：

| 变量 | 必需 | 说明 |
| --- | --- | --- |
| `L12_SMTP_HOST` | 是 | SMTP 主机名 |
| `L12_SMTP_PORT` | 否 | 端口，默认 `587` |
| `L12_SMTP_USERNAME` | 视供应商而定 | SMTP 用户名；允许受控的无认证中继为空 |
| `L12_SMTP_PASSWORD` | 视供应商而定 | SMTP 密码或应用专用密码 |
| `L12_SMTP_FROM_ADDRESS` | 是 | 已由供应商验证的发件地址 |
| `L12_SMTP_FROM_NAME` | 否 | 发件人名称，默认“十二军团” |
| `L12_SMTP_ENABLE_SSL` | 否 | 默认 `true` |
| `L12_PUBLIC_BASE_URL` | 是 | 邮件链接的站点根地址；生产应使用 `https://legion-12.com` |

只要主机、发件地址或公开站点地址缺失/无效，发送器就保持未配置状态：绑定接口返回安全失败，匿名找回接口仍返回统一接受文案，但不会生成可用令牌或尝试联网。

## 上线前外部选择

需要运维方提供或确认：SMTP 供应商、发信域名、已验证发件地址、端口与 TLS 模式、凭据注入方式、生产公开根地址，以及 SPF/DKIM/DMARC 记录。凭据不得写入 `.env` 样例、提交记录、日志或管理审计。

建议在供应商侧限制仅允许指定发件地址，并配置退信/投诉处理与配额告警。当前实现是供应商无关的标准 SMTP；测试使用注入的假发送器，不访问外部服务。

## 安全与兼容边界

- 邮箱验证令牌有效期 24 小时；密码重置令牌有效期 30 分钟。原始令牌只进入邮件链接，平台仅持久化 SHA-256，令牌一次性消费，新请求会使同用途旧令牌失效。
- 邮件链接将令牌放在 URL fragment；恢复页读取后立即清除 fragment，并要求用户明确点击确认，避免预览机器人通过 GET 自动消费令牌。
- 忘记密码对存在、不存在、未验证、禁用和已删除账号使用相同响应；限流键由邮箱/IP/账号等主体的哈希构成，不在限流记录中保存明文邮箱或 IP。
- 匿名找回的邮件投递在统一响应路径之后排队，降低 SMTP 时延造成的账号枚举差异；发送失败的令牌立即作废。SMTP 单次发送超时为 15 秒。
- 密码重置会撤销全部会话。管理员重置使用产品指定的临时密码 `123456`，同时撤销全部会话并强制先修改密码；根 `Admin` 和操作者自身不能经后台重置或删除。
- 管理员重置与逻辑删除进入既有命令总线，强制幂等键、目标账号版本和理由，避免重放或并发覆盖。
- 逻辑删除会清空邮箱、牌库、公开牌库、好友关系，匿名化 Bug/赛事功能数据和对局姓名/牌库标签。独立安全审计按既有保留策略继续保存，以满足追责和恢复演练要求。
- 快照字段均为加法式默认字段，旧账号和旧快照可直接加载。新版本写入邮箱/令牌字段后，如回滚到不了解这些字段的旧二进制，旧程序下一次保存可能丢弃这些新字段；回滚前必须使用部署脚本的同版本运行数据备份。

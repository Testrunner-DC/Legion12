- 本地工作区为唯一事实来源；本批开始时存在大量尚未提交的前后端卡效改动，禁止远端覆盖、重置或整文件替换。

### BUG-20260818-01 太阳城特殊支付被拆成多个不一致流程

- 现象：场上存在活跃的〈陵墓守卫〉时，部分费用仍由系统自动支付或弹出“是否使用陵墓守卫”，玩家不能直接组合选择活跃士气与陵墓守卫。
- 历史记录匹配：命中本批基线中的“士气支付分支重复”根因。
- 根因：打出、盖伏反击战术、位移、主动效果与效果结算分别实现支付，没有共享精确资源选择协议。
- 同类扫描：遍历打出、盖伏、位移、主宰/阵营/军团/圣物主动效果、效果续接、临时士气与陵墓守卫支付入口；公共命中为 `CreateResourcePaymentPrompt`、`TryConsumeSelectedResources` 与 `CommitActiveAbility`。
- 修改：统一建立资源支付 Prompt；玩家点击场上的活跃士气圆形或活跃陵墓守卫后确认，服务端按实例 ID 校验并支付；没有陵墓守卫时继续使用普通同质士气流程。
- 验证：后端全量测试 159/159 通过；前端 UI 契约 14/14、TypeScript 与生产构建通过。
- 防回滚：支付 Prompt 使用实例 ID，入口复用公共构造与消费函数；测试保留精确资源选择与各入口回归断言。

### BUG-20260818-02 能力可用性只按弹框整体判断

- 现象：不能发动的效果仍可点击；触发/响应效果会被误当作主动效果；梅杰德弹框重复展示原文，且触发效果缺少灰置按钮。
- 历史记录匹配：命中本批基线中的“能力视图缺少逐能力状态”根因。
- 根因：快照只发送字符串，没有每个能力自己的 `enabled`、禁用原因和 `triggerOnly` 元数据；前端只能启停整个弹框。
- 同类扫描：扫描主宰、阵营、军团、圣物、试炼和特殊区域能力；同时检查主阶段、回合归属、回合一次、资源不足与触发专用条件。
- 修改：能力视图统一为对象；按钮内直接显示完整效果文本，弹框不再重复原文；不能发动与触发专用能力灰置且不可点击。梅杰德主动额外支付和对方回合受伤触发均接入对应公共流程。
- 验证：新增“不可用/触发专用能力仍可查看但不可主动发动”与“梅杰德受伤触发选择陵墓守卫及位置”测试；后端全量 159/159 通过。
- 防回滚：快照字段成为前后端类型契约；触发专用能力有服务端拒绝与前端禁用双层保护。

### BUG-20260818-03 可点击主宰失去悬停详情

- 现象：主宰可点击发动效果后，鼠标悬停不再显示卡牌详情。
- 历史记录匹配：无直接条目，归入“交互动作不得吞掉详情查看”公共约束。
- 根因：主宰按钮只绑定点击动作，没有同步发送 hover/focus 详情事件。
- 同类扫描：检查主宰、阵营入口、战场卡牌、叠放卡和特殊区域中同时可点击与可查看的元素；公共原则为点击动作与悬停详情并存。
- 修改：主宰按钮在 `mouseenter` 与键盘 `focus` 时发送主宰卡牌详情，同时保留点击发动能力。
- 验证：前端 UI 契约、类型检查与生产构建通过。
- 防回滚：将“可点击不取消 hover/focus 详情”加入同类扫描矩阵。

### BUG-20260818-07 对方回合静态兵力被进攻流程重复追加

- 现象：4000 兵力的〈铁盾拉葛莎〉被进攻并由〈佣兵部队〉响应后变成 5000，静态修正被重复累计。
- 历史记录匹配：命中“持续兵力必须由统一派生值重算”的同类根因。
- 根因：同一个“对方回合前排兵力+1000”既在 `DerivedStats` 快照重算中处理，又在进攻开始时直接写入实例兵力；被进攻事件因此产生第二次永久加值。
- 同类扫描：遍历所有按回合、位置、阵营和公开场面计算的持续兵力修正；删除进攻入口的单卡写值分支，统一由 `GetTurnAndPositionContinuousTroops` 计算，覆盖 S01-0107、S01-0212、S01-0312、S02-0004、S02-0007、S02-0519、S02-0615。
- 修改：进攻不再修改防守方静态兵力；响应、快照与结算只重算派生值。
- 验证：新增“拉葛莎被进攻且佣兵响应后仍仅+1000”回归测试；全量后端测试 163/163 通过。
- 防回滚：持续效果禁止在事件入口直接 `Troops +=`；同组卡使用理论测试，拉葛莎另保留完整进攻/响应流程测试。

### BUG-20260818-08 对局记录正文无法正常换行

- 现象：长日志和可点击卡名混排时横向溢出或在错误位置断行。
- 历史记录匹配：无单独条目，归入“日志必须可完整复盘”约束。
- 根因：标签与正文使用同一个行内流，正文没有可收缩容器，`word-break` 无法对包含按钮的混合内容稳定生效。
- 同类扫描：检查实时对局日志与历史回放日志；实时日志统一增加 `event-message` 容器，历史记录继续复用事件文本展示。
- 修改：日志条目改为“固定标签 + `minmax(0,1fr)` 正文”，正文启用正常空白、任意长串换行和断词。
- 验证：UI 契约检查 18/18 通过；生产构建在主工作区复验。
- 防回滚：UI 契约要求 `event-message` 与 `overflow-wrap:anywhere` 同时存在。

### BUG-20260818-09 手牌可打出判断仍使用印刷费用

- 现象：〈血斧艾瑞克〉在 4 士气时被灰置；〈卡诺匹斯罐 二〉生效后，下一张战术费用角标没有显示 0。
- 历史记录匹配：命中“费用计算不能只存在于提交命令时”的同类问题。
- 根因：服务端权威支付已能计算额外付费、免费次数和动态减费，但快照与前端高亮仍读取 `cost/currentCost`。
- 同类扫描：扫描自伤减费、卡诺匹斯免费战术、槲寄生符咒、阵营/主宰减费、天灾增费和持续费用修正；统一通过手牌快照的 `playCost` 输出当前最低合法打出费用。
- 修改：服务端逐张计算 `playCost`；手牌费用角标、可打出高亮、Prompt 详情与选中卡牌详情优先读取该值。免费次数被使用或回合结束后，下一次快照自动恢复正常费用。
- 验证：新增艾瑞克 4 费可选与免费战术显示 0/使用后消耗测试；全量后端测试 163/163、UI 契约 18/18 通过。
- 防回滚：前后端类型中保留 `playCost`，UI 契约禁止手牌可打出判断退回印刷费用。

### BUG-20260818-10 无合法支援仍要求防守方确认

- 现象：前排军团被攻击时，即使同列后排没有可支援军团仍弹出支援步骤。
- 历史记录匹配：命中战斗流程中“响应结束后应按合法动作自动跳过”的规则。
- 根因：进攻堆叠结束后无条件停在 `Defense`，没有先计算同列后排支援的合法性。
- 同类扫描：检查主宰抵挡、军团支援、必中、后排不能支援和兵力不足五类分支；仅军团支援在候选为空时自动结算，主宰抵挡仍由玩家决定。
- 修改：新增统一的合法支援判定；候选为空时记录“跳过支援选择”并自动执行伤害结算。
- 验证：更新近战、远程、同一时点阵亡、触发和傀儡改目标测试；新增离场重置流程测试；全量后端测试 163/163 通过。
- 防回滚：所有军团进攻共享 `HasLegalLegionSupport`，测试同时覆盖无候选自动跳过与有候选保留支援窗口。

### BUG-20260818-11 兵力不高于 0 未作为全局状态检查

- 现象：效果使军团兵力降到 0 或负值后，军团可能继续留在战场直到后续战斗代码处理。
- 历史记录匹配：命中规则书“核心概念·兵力值”的状态规则。
- 根因：阵亡只散落在战斗和若干单卡效果中，没有在每个权威命令完成后统一检查。
- 同类扫描：扫描战斗伤害、临时减兵、持续减兵、设定兵力、天灾减兵和入场减兵；统一在每个成功命令后重算并处理所有不高于 0 的军团。
- 修改：增加可迭代的状态式阵亡检查与同一时点触发批次；天灾导致的阵亡明确抑制阵亡时/离场时触发。
- 验证：槲寄生、梅林、阿瓦隆、破败仪式等旧测试改为验证即时阵亡；全量后端测试 163/163 通过。
- 防回滚：状态检查位于统一命令出口，不依赖逐卡调用；天灾 Prompt 在结算前捕获抑制标记，避免堆叠移除后误触发。

- 防回滚：任何新增离场路径必须调用公共重置；同类扫描矩阵增加区域移动检查项。

### BUG-20260818-15 天灾伤害被误判为对方效果

- 现象：天灾对梅杰德一方主宰造成伤害时，错误触发梅杰德“因对方进攻或效果受到伤害”的效果。
- 历史记录匹配：命中“触发条件不能从当前回合玩家反推”的规则内核约束。
- 根因：主宰伤害只记录受伤玩家，梅杰德使用 `ActivePlayer != damagedPlayer` 推断来源；天灾由回合玩家推进结算，因而被误判为该玩家的效果。
- 同类扫描：遍历全部 `DamageMaster` / `DamageMasterNonLethal` 调用；百鬼夜行、暴怒之罪、堙灭、无眠之夜持续效果及天灾造成的圣物使用伤害均标记为中立，进攻显式记录进攻玩家，其余堆叠效果从权威堆叠来源取得控制者。
- 修改：主宰伤害公共入口增加显式来源语义；梅杰德仅在来源确为对手时建立触发候选，天灾中立伤害仍允许其他不限定来源的受伤时反击战术正常检查。
- 验证：新增“中立天灾伤害不触发梅杰德”测试，并保留“对方进攻触发梅杰德”测试；后端全量 167/167 通过。
- 防回滚：禁止再以回合玩家推断伤害来源；新增天灾伤害入口必须显式标记 `neutralSource`。

### BUG-20260818-16 双方弃牌只同时展示、没有同时提交

- 现象：〈黑胡子蒂奇〉虽让双方同时看到弃牌选择，但先确认的一方手牌会立即变化；同类天灾也存在先提交、后等待的问题。

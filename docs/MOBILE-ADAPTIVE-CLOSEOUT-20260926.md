# 全站移动适配与宽屏对战修复报告（2026-09-26）

## 修复结论

移动对抗报告中的五项产品问题已经全部按共享布局原则收口，没有针对玩家截图的单一分辨率写特判：

1. 图鉴在 320—700px 窄屏下不再保留隐藏详情栏宽度，卡池恢复完整可操作空间。
2. 低高度横屏不再依赖物理横屏或设备类型；可用高度不足时统一切换为抽屉导航。
3. 移动对战的“对局记录”入口与弹框最小化恢复条分属独立槽位，可同时存在并保持命中。
4. 选择弹框中的竖卡和横卡分别保持 5:7 与 8:5，候选框扩张不再拉伸卡图。
5. 宽屏双方计时器位于战区垫和右侧栏之间的独立轨道：对方贴上沿，我方贴下沿，均不侵入两侧组件。

## 对抗验收

- 非对战移动端：11 个真实页面、11 个边界宽度、123 张首屏截图；另补长页面滚动到底部检查。
- 低高度横屏：701×360、844×390、1024×600、1920×600 均使用紧凑导航且入口可达。
- 后台与个人中心：12 个移动／桌面视口，无横向溢出。
- 移动对战弹框：555 张固定截图、60 类弹框、18 个安全区和 32 组随机扫描通过。
- 同级选项：252 条几何断言通过，覆盖文字选项、混合横竖卡、页脚、支援／抵挡、工具和士气操作。
- 宽屏对战：12 个宽屏比例 × 7 类状态，共 84 个场景通过。
- 计时轨：1068 条几何断言、36 张截图通过；双方计时与战区垫、右侧栏交叠面积均为 0。
- 牌桌网格：11 个比例通过，移动端没有继承桌面计时轨列。

## 变更边界

本批只调整响应式布局和对应的浏览器回归门禁，不改变卡牌规则、对局状态、计时数值、服务端数据模型或权限逻辑。完整 Batch 已通过：性能与 P0—P4 架构锁、349 项 UI 契约、Vue 类型检查、正式与 testrun 双构建各 440 模块。干净 Release、推送与测试服读回结果在发布完成后记录到部署报告。

## FAQ 逐类差距

### 已覆盖

- 未写“可”的【登场时】效果必发；写“可”的效果使用 Prompt。（FAQ 1）
- 冒号前费用先支付，效果被无效不返还；主动战术结算期间视为在场但不占格。（FAQ 7、10）
- 主宰血量为 0 立即结束；恢复不超过上限；非致命伤害不能失去最后 1 点血量。（FAQ 4、8、11）
- 同列后排支援、当前回合兵力减损累积、进攻目标离场后不自动改选。（FAQ 15、16、56）
- 一个效果完整结算后再检查新增触发；结算中触发进入额外堆叠。（FAQ 43 及用户提供的堆叠范例）
- 印刷费用与实时费用字段分离；需要印刷费用的效果读取 `Cost`。（FAQ 47）
- 检索不命中时向对手展示；记录中保留展示事件。（FAQ 49）

### P0：规则正确性缺口

1. **宣言目标必须先于费用支付（迁移中）**：已增加 `PendingActivation`，支持多步骤目标/位置声明、最终合法性复核、支付费用、入栈；基础主动效果、六项 S1 阵营目标效果及西施的“手牌＋位置”已迁移。剩余 S1 登场时、进攻时和多段触发仍需逐卡迁移。
2. **同一时点多个触发由拥有者排序（公共入口已接入）**：`TriggerBatch` 按回合玩家、对手依次建立批次，同一拥有者多个触发会收到排序 Prompt；已覆盖同时阵亡、离场、进攻后、主宰受伤及对方战术结算后的触发。后续新增触发必须通过同一候选收集入口接入。
3. **所有空牌库操作统一失败（门面完成、调用点迁移中）**：`LibraryOps` 已统一抽牌、查看、弃置顶部、检索、置顶/置底、顶部重排和洗牌；核心抽牌、洗牌及 S1 磨牌入口已接入，剩余逐卡直接操作牌库的旧实现仍需替换。
4. **持续修正与免死重算（骨架完成）**：`DerivedStats` 已建立“基础/当回合 → 设定值 → 持续修正”的重算顺序；免死设为 1000 后会重新应用持续减益，最终不高于 0 仍阵亡。旧卡效中直接修改 `Troops` 的调用点仍需迁移到分层修正。
5. **多段效果独立时点与目标预声明**：分段效果已能形成多个效果项目，但并非所有多段卡都在第一段开始前保存后续目标。FAQ 20、21、54 需要统一的复合效果声明模型。

### P1：完整机制缺口

- S2 115 张已进入卡牌档案，少量通用效果存在代码入口，但没有合法标准预组/构筑来源，也没有逐卡 FAQ 回归；不能称为完整可玩 S2。
- 静态覆盖复核显示：S1 的效果卡均已有卡号入口（额外通用士气除外），但仍需逐条语义测试；S2 仍有大量卡牌没有卡号入口。S02-0015 至 S02-0018 已完成反击分类、权威响应时点、结算与语义回归。后续状态报告必须继续区分“数据已收录”“卡号有入口”“语义已测试”三种状态。
- 奥林匹斯神力、彼界试炼/符文与晋升叠放底座已进入对战状态模型，并有原子费用、状态继承和共同离场内核；尚未完成标准 S2 构筑来源与逐卡效果迁移。（FAQ 26、31、32、44）
- “击杀来源”与“【击杀时】”目前主要用布尔结果处理，尚未形成可传递的来源对象；S2 接入前需按 FAQ 53 分开记录原始战斗击杀与效果连带阵亡。
- 断线重连、观战身份和房间保留时长此前按用户决定暂不引入限时；目前断线后只广播离线状态，没有恢复原座位的会话令牌。

## 下一阶段优先级

1. `PendingActivation`：目标/模式/位置预声明 → 校验 → 支付费用 → 入栈；先改公共框架，再迁移所有需要目标的 S1 效果。
2. `TriggerBatch`：收集同一时点的全部触发，由拥有者排序；回合玩家先建立自己的批次，再由对手建立批次。
3. `LibraryOps`：统一抽牌、查看、展示、弃置、检索、排序、洗牌与空牌库失败；补每种操作的边界测试。
4. `DerivedStats`：基础兵力、当回合修正、持续修正、设定值和免死后的重算顺序。
5. 规则内核稳定后，再做 S2 专属区域与逐卡效果；同时将回放升级为复用实战棋盘的只读模式。

## 本轮验证

## 规则内核推进（2026-08-16）

- `PendingActivation`：支持单步与多步声明；目标失效时不支付费用、不入栈。已迁移高天原主宰/草薙剑/山河社稷图目标效果、奥尔加、凌霄宝殿、孟婆、众神之乡、梅杰德、天照大神与西施。
- `TriggerBatch`：同一时点触发按回合玩家、对手分批建立；拥有者可排列同批触发的实际结算顺序。
- `LibraryOps`：抽牌不足与弃置顶部不足均为原子失败；查看不修改牌库；检索、置顶、置底、顶部排序和洗牌具备统一入口。
- `DerivedStats`：免死设定值之后重新叠加特洛伊木马等持续修正；晋升底座不贡献兵力与文本，状态/词条转移至晋升者，整体离场时一同移动。
- S2 专属区：快照及前端预留神力、符文与试炼显示；神力/符文费用和晋升叠放已有边界测试，逐卡卡效仍按阵营推进。
- 自动测试由 45 项增至 58 项；前端生产构建通过。

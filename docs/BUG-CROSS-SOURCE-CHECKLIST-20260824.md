## 四、本批公共根因与防回滚门禁

1. 特殊起始军团不再按卡号特判：构筑计数、开局区域、区域准入和离场替代统一读取卡面规则。
2. 普通编号军团必须具有印刷费用与兵力；任一新增空值会让完整规则测试失败。
3. 墓地登场效果必须验证真实候选、实例移区与棋盘选位，不以“已有分支”代替端到端测试。
4. 双方公开信息确认以独立 `PromptId` 结算；一方的重复/过期操作不能消费另一方请求。
5. 三来源的合并结果以本清单为人工验收入口；复测后可直接把对应 `[ ]` 改为 `[x]`，并把原场景信息回填到修复登记。

# BATCH305 本地验收记录

日期：2026-09-09。范围：本次四项对战需求及用户单独同意的存档战场恢复修复。未同步、部署或修改线上数据。

## 实际变化

1. 短视口保留可读缩放，允许滚动到对战底部，设置和手牌不再被 overflow 隐藏。
2. 窄屏对战、回放和牌库编辑器共用逻辑横屏视口；不支持原生方向锁时使用整体 CSS 横屏。弹框、点击坐标与动效坐标一并转换；输入时退出强制旋转以配合键盘，离开页面恢复正常方向。
3. 宫廷魔术师在战场上选盖伏对象；同类 field-card/covered-counter 共用模式修正。可选位置不意味着公开对方盖牌身份。
4. 同时触发按玩家选择的发动顺序入栈、逆序结算；响应成功后保留本方优先权直到让过。响应可选择任意合法栈项，唯一目标自动绑定，多目标显示每段全文和公开详情。目标失效不自动换绑，不重复支付；同一傀儡实体不能重复入栈。
5. 检查点正确还原双方2×3战场、盖伏与休整信息；缺失或畸形战场拒绝恢复，不默认为空场。此修复不代表普通在线重连都曾丢牌，也不重写旧线上数据。

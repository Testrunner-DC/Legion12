# 卡效实现参考与优先级

当前已进入卡效实现与语义审计阶段。本文件记录资料入口，避免将“参考实现”误当成十二军团正式规则。

规则裁决优先级：最新勘误/卡牌调整 > 卡面文字 > 官方 Q&A > S2 规则书 > 既有代码。

参考来源：

1. [十二军团卡牌查询](https://twelve-legions-card-lookup.pages.dev)：后续补齐至第三季的卡牌与效果资料入口。
2. `docs/l12`：从旧十二军团项目选择性迁移的规则、审计和测试结论。
3. `服务端WebSocket/Effects` 与 `服务端WebSocket/Game`：GrandUMI 的服务端权威卡效架构，仅参考效果注册、目标选择、原子操作和结算队列的组织方式。
4. `docs/grandumi`：模板协议与架构说明。

不迁移 GrandUMI 卡图或历史对局。实现每批卡效时必须增加可复现测试，并在 SQLite 事件中保留命令、事件、快照和状态哈希。

根因审计不再以“卡号是否在源码出现”作为完成标准。每张卡需分别核对：公开的发动按钮、合法时点/目标、费用支付、是否可选、入栈、结算、区域移动、持续修正、日志与回放数据。公开了主动能力但没有提交/结算处理器属于阻断缺陷。

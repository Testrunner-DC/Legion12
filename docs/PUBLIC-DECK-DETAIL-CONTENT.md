# 公开牌库详情内容闭环

日期：2026-09-24
状态：独立工作树实现与 Batch 验证完成，待 Main 对抗复核；未推送主线，未部署。

## 本批范围

- 详情页在既有完整构筑之外增加指南、对局建议、版本、对局和随机起手。
- 指南包含构筑思路、起手建议、关键牌与配合、常见展开、替换建议；空内容明确显示“作者暂未填写”，不自动生成文案。
- 对局建议由作者按敌方主宰维护思路、关键牌和建议换牌；不计算胜率、评分或作者总战绩。
- 版本按时间倒序展示全部长期保存的公开版本、完整旧牌表和主牌/士气/试炼额外区数量差异。
- 对局只允许展示能够权威绑定到具体公开版本的记录。当前对局采集没有该绑定，因此返回准确空态，不用作者历史对局替代。
- 随机起手仅从当前公开版本的主牌中在浏览器内随机抽取 6 张；重新抽取不修改牌库、不写后台、不生成对局记录。实战可选开局效果和调度仍由服务端处理。

## 存储与长期保留

- SQLite 架构版本升至 5。
- `published_deck_content_payloads` 对指南与对局建议的规范化 JSON 计算 SHA-256，相同正文只保存一次。
- `published_deck_content_heads` 保存当前修订引用；`published_deck_content_revisions` 只追加修订号、正文哈希、作者和时间。
- 指南每段最多 1200 字；单个对局建议字段最多 800 字、最多 64 个敌方主宰；纯空白归一为空字符串，控制字符与脚本协议文本拒绝写入。
- 内容正文、内容修订、全部公开构筑版本均不按时间、数量或引用状态自动删除。
- `published_deck_versions.name` 保存版本当时的牌库名称；旧数据库升级时以当前公开名称回填已有版本，之后名称或构筑变化都会形成新版本。

## 权限与输出安全

- 读取公开详情仍允许匿名访问。
- 只有当前公开牌库的作者可以更新指南和对局建议；未登录返回 401，非作者返回 403，不存在返回 404。
- 前端只使用 Vue 文本插值呈现作者正文，不使用 `v-html`。

## 迁移与回滚

升级由幂等建表和 `published_deck_versions.name` 条件加列完成；旧构筑正文、版本与公开入口不重写、不删除。切回旧版本时保留数据库文件，新表和新增列会被旧程序忽略；再次升级可继续读取全部修订。生产迁移前仍应按既有存储流程保留数据库、WAL、SHM 与 JSON 迁移备份。

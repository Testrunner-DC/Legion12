# F2 私人牌库对象写受控启用

用户批准打开 F2，并明确授权本批测试服部署；未授权本批正式服部署或维护变更。先收口 E1/D3，再在唯一干净候选上完成 Release、同步与测试服切换。

## 启用边界

- `L12_PRIVATE_DECK_OBJECT_PERSISTENCE` 未设置时仍为 false，只接受 true/false（忽略大小写与首尾空白）；非法值在建运行目录及打开数据库前拒绝启动，不回显原始值。
- Program 在接受请求前一次性捕获配置。运行中改环境变量不热切换，重复应用拒绝。
- 测试专用 service 显式配置 true；测试环境文件可显式 false 覆盖，以同版本重启回到全量路径。正式 service 未加入该设置，默认关闭。
- `GET /api/admin/storage/private-deck-persistence` 仅允许运营读取权限，返回捕获开关、实际对象／全量／只读模式、可写性、镜像健康及需重启信息。匿名401、普通玩家403、POST405，响应不缓存，不显示路径／账号／牌表，不执行扫描或写入。
- 仅私人牌库增删改走对象路径。公开版本、赛事、账号、赛季专用事务与初始迁移仍使用原有出口。schema、CAS、镜像和恢复协议不变。

## 门槛和回退

新增启动专项 26 个展开用例，含非法配置、一次捕获、关闭重启保留最新正文／19副牌库／墓碑、只读降级、镜像失败以及真实HTTP权限和只读无副作用。首轮完整平台实跑400/407通过，7失败均定位为新测试夹具：用户名触发广告导流规则、二次改名应新增第三墓碑。已修合法名字，并加强旧墓碑逐字段不变＋新增唯一一行断言，不能删掉风险断言。Main最终完整平台407/407、失败／跳过0；规则6076/6076，完整Release另记发布回执。

既有双向CAS、丢响应、同版本关闭回退、恢复和故障专项保留。此前对象基准20／1200行保存P95中位7.249／8.830ms、牌库SQL5／5、影响行3／3，仅是合成工程预算，不是线上SLA；本次启动开关不修改这些事务实现。

同版本关闭回退必须保留最新数据库，不能用旧备份覆盖期间成功保存的牌库。发生双读不一致、恢复失败、错误率异常或异常冲突，先停止扩展并关闭对象模式；不能宣称启用零风险。正式服真实数据副本预演仍是正式启用前独立门槛，本次测试服不读取或修改正式玩家库。

## 玩家可做的验收

使用测试服自己的牌库，建议先复制预组为验收用牌库：

1. 新建、保存、刷新／重新登录，卡表与名称保留。
2. 改名后只有同一副牌库，不产生旧名副本；已选出战牌库仍指向该牌库。
3. 两个标签页打开同一副。A修改保存后，B使用旧内容保存应提示冲突／要求刷新，不得静默覆盖A的结果。
4. 删除后刷新与重新登录，不应复活；其他牌库不受影响。
5. 保存时断网或响应不明确，先恢复网络并读取已保存结果，不应靠反复点击制造副本。

UI不能证明服务器使用了对象写；Main另行核对受保护状态接口、数据库恢复、并发版本及部署身份。服务重启、故障注入、数据库副本和同版本关闭回退由Main负责，用户无需操作服务器。

## 上线验收回执要求

测试服目标提交、公网HTTP／WebSocket、F2实际模式、受控验收牌库CRUD／冲突、正式服版本及启动时间未变分别记录。启动开关与测试service已实现不等于测试服已部署；最终线上结果另追加回执。

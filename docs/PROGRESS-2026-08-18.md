# 十二军团 Web 进度记录（2026-08-18）

## 本批完成

- 对战 UI：动态费用增减色、主宰生命/牌库/墓地计数器、已选目标识别、对手在线状态、返回大厅与投降入口、房主规则展示。
- 日志隐私：未公开的抽牌与加入手牌不再向对手泄露卡名。
- 平台账号：注册、登录、退出、修改密码、用户名禁用词、角色权限与默认最高管理员。
- 管理后台：首页/资讯/规则内容维护、账号角色管理、Bug 状态和后台备注管理、运行能力清单。
- 全局反馈：首页、资料页、牌库、赛事与对战均使用同一 Bug 反馈入口，自动附带页面与客户端信息。
- 赛事中心：创建、规则设置、裁判、报名、配对、房间码、准备、轮次开始、超时判负、暂停、补时、判罚、自动下一轮、赛事结束和赛后档案。
- 加载优化：生产环境增加有界卡图缓存，不缓存 API、WebSocket 或对局状态。
- 防回滚：修复〈天下布武〉免费移动迁移遗漏，并更新最终天灾公开信息测试。

## 数据与安全

- 平台账号、Bug 和可编辑内容由服务端 JSON 持久化。
- 密码使用随机盐 PBKDF2-SHA256 存储，客户端不保存明文密码。
- 默认最高管理员账号由用户指定；首次运行创建后可在“我的”页面修改密码。
- 跨域来源仅允许本机地址或显式环境配置，不再使用任意来源。

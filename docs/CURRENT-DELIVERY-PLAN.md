## 五、调度原则

- 同一时间最多一个共享代码写入批；方案评审、差距盘点和只读验收可并行。
- 子对话只交付干净、可核验的有界结果；Main 负责重放、冲突处理、最终 Release、推送和部署。
- 已进入 `origin/main` 的历史工作树不再代表待办；只有主线缺口才进入新批次。
- 不以局部测试、静态断言或“已经写了代码”替代独立验收、完整门禁和线上复测。
- Git 推送与部署分离；推送不推定部署，部署不推定解除维护。
